# MIS Executive Dashboard

## Project Overview

This project is an MIS Executive Dashboard created using Microsoft Excel.

The dashboard is designed to analyze business and sales data and present important information through interactive reports and visualizations.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard

## Key Analysis

- Total Sales
- Total Orders
- Sales by Category
- Sales by Month
- Sales by State
- Salesperson Performance
- Top Products
- Payment Mode Analysis

## Project File

The Excel workbook contains the complete dashboard and analysis.
